# Gerador de Croqui

Ferramenta web para montar o layout de blocos e parcelas de um experimento a campo — define comprimento/largura da parcela, quantidade de blocos e parcelas por bloco, largura dos carreadores, delineamento (sequencial, DIC ou DBC) e nomes dos tratamentos.

Cada parcela sai colorida por tratamento, com legenda no próprio croqui. Exporta:

- **KML** com as medidas exatas em metros, georreferenciado (SIRGAS 2000 / UTM 23S).
- **PNG** do croqui, pronto para compartilhar.

Abra `index.html` direto no navegador, sem instalação.
